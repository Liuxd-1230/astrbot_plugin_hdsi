# 新手部署教程

适用版本：`v1.0.0`

HDS Interlude 是 AstrBot 的持续叙事聊天插件。插件使用共享主剧本保存角色状态、
关系分支、已发生事件、待处理计划和长期记忆。用户消息会进入当前活动场景；
主模型在同一次请求中续写已经发生的生活，并决定是否发送、延迟发送或暂不发送消息。

## 你将得到什么

- 一个有自己日程、事务和情绪的角色，而不是一个等待提问的问答机器人。
- 角色可能立即回复，也可能"看见但不回"，也可能过一阵再回——这些都是剧情的一部分。
- 长期记忆、承诺与未完成事项会在之后的对话和自动推进中持续出现。

## 前置条件

- AstrBot v4.x 已部署并可以打开 WebUI（本文以 v4.27 验证）。
- 至少配置了一个可用的 LLM Provider（WebUI → 服务提供商），模型需支持
  JSON 结构化输出（主流 Chat 模型均可）。建议使用能力较强的模型；
  小型或不稳定的模型更容易格式失败或关系跳跃。

## 第一步：安装插件

1. WebUI → 插件 → 从仓库安装/本地导入 `astrbot_plugin_hdsi`。
2. 安装后在插件列表确认状态为已启用，日志中出现：
   `[hdsi] HDS Interlude 已加载 v1.0.0（持续叙事运行时，非 Persona 插件）`。

## 第二步：绑定模型槽位

插件配置（WebUI → 插件 → astrbot_plugin_hdsi → 配置）：

- `main_model`：留空 `inherit` = 跟随当前会话使用的 Provider（推荐新手）。
- 也可以填 `provider_id:model` 显式指定；多个候选用英文逗号分隔即故障切换链。

其余高级配置全部在管理面板中调整，不需要动这个配置文件。

## 第三步：打开管理面板

WebUI 左侧 → 插件页面 → HDS Interlude。首次建议按顺序填写：

1. **Canon**：主角名（例如"栖"）、主角背景（性格/日程/说话方式）、世界设定、
   地点、时区（默认 Asia/Shanghai）、文风。
2. **Runtime**：保持默认即可。注意两个开关：
   - `allow_proactive_messages` 默认关闭（主动联系需要显式开启）；
   - `auto_create` 默认关闭（需要用命令显式创建剧本）。
3. **维护** 页随时可看当前故事状态。

## 第四步：配置白名单（重要）

HDSI 使用显式白名单，空白名单 = 不拦截任何消息（入口关闭）。两种方式任选：

- 管理面板目前通过聊天命令最方便；直接在目标账号的私聊里执行第五步，
  如果提示"未获授权"，在管理面板 Models/Runtime 之外确认你已在插件配置或
  平台白名单中加入该账号。

对于 webchat（仪表盘聊天页）：机器人账号 ID 填 `webchat`，
用户 ID 填你的仪表盘用户名（如 `rosemary`）。

对于 QQ（aiocqhttp/NapCat）：机器人账号 ID 填机器人 QQ 号，用户 ID 填你的 QQ 号。
群聊需要单独把群号加入 group 白名单。

## 第五步：创建主剧本

在已授权账号的私聊中发送：

```text
hdsi init 栖
```

看到「已创建 栖 的共享主剧本，并加入 xxx」即成功。其他获授权账号之后
私聊时会自动加入这同一段生活（各自保留独立关系分支）。

## 第六步：开始对话

直接发送普通消息（不要加命令前缀），例如：

```text
栖，晚上好！今天过得怎么样？
```

正常情况下日志会出现三段式：

```text
[用户消息] 栖 (*^▽^*) 收到参与者私聊消息
├─ (•̀ᴗ•́)و 模型调用开始 …
├─ (ﾉ´ヮ`)ﾉ*: ･ﾟ 模型调用完成 …
└─ (・ω・)ノ 消息投递开始
```

角色可能立即回复，也可能沉默——沉默是剧情的一部分，不是故障。

## 第七步（可选）：验证自动推进

对话结束后约 10/20 分钟会有一次短期补写，之后按 ~40 分钟节奏推进角色生活
（深夜休息窗口自动降频）。你可以随时发送 `hdsi advance` 手动触发一次，
再到管理面板 Script Viewer 查看补写的剧本。

## 第八步（可选）：开启进阶能力

按顺序逐个开启并在每一步观察行为：

1. `runtime.allow_proactive_messages` + Agency 配置 → 主动联系。
2. Alter System（默认开）→ 长对话后观察 `[情绪追踪]` 日志。
3. Embedding 槽位 → 长期事实语义检索。
4. Browser 开关 → 角色可提出只读网页观察。

## 常见问题

**发消息没有反应？**
检查白名单是否包含你的账号；检查 `hdsi status` 是否显示活动故事；
查看日志是否有「故事不存在或已暂停」。

**回复被默认人设抢走了？**
说明 HDSI 未拦截：多半是账号不在白名单（HDSI 只拦截它管理的会话）。

**角色一直不回消息？**
先区分 silent（seen=true, mode=none）与 unseen（seen=false）：
用 `hdsi script` 看最近剧本；这是叙事决策而非故障。连续多次沉默可
临时调低 `context_entry_limit` 或更换主模型观察。

**想清空重来？**
聊天执行 `hdsi reset` 并按提示确认 y；或管理面板 Maintenance → reset story。

更多配置细节见 CONFIGURATION.md；完整命令见 COMMANDS.md。
